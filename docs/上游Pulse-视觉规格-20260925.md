# 上游 Pulse 视觉规格表（源码提取，2026-09-25）

来源：tmp\Pulse-upstream（qunqin24/Pulse main，v1.5.0 当日）。文件引用均相对 Sources/Pulse/。

## 颜色（UsageTint.swift）

| 名称 | 值 | 用途 |
|---|---|---|
| pulseGood | rgb(0, 0.90, 0.55) = #00E68C | 用量 < 50% |
| pulseCaution | rgb(1, 0.76, 0.15) = #FFC226 | 50% ~ 警报阈值（**黄档**） |
| pulseWarning | rgb(1, 0.31, 0.26) = #FF4F42 | > 警报阈值 |
| pulseExhausted | rgb(0.85, 0.09, 0.13) = #D91721 | 耗尽（更深更平，数字同染） |
| 轨道 | primary.opacity(0.18) | 环轨道；进度条 0.17 |
| 文字分级 | primary @ 1 / 0.9 / 0.55 / 0.45 / 0.4 | 标题/数字/次要/重置时间/脚注 |
| RingTint 预设 | #4099FF #B380FF #FF70B8 #FF8F33 #33D1D1 | 自定义环色建议 |

警报阈值档位：60/70/75/80/85/90，默认 75。语义：绿 < 0.5 ≤ 黄 < threshold ≤ 红；spent/≥1 恒深红。

## 面板材质（PanelSurface.swift）

- 默认**纯黑 .black**（非玻璃）；玻璃可选：`.clear` glass + 黑 dim = black.opacity((1-transparency)*0.6)，transparency 默认 0.5 → 黑 0.3。
- 哲学：实心面在任何背景上都可读；玻璃是 offered 而非 assumed。

## DockLayout（UsageDockView.swift）

rail 宽 64、verticalPadding 46(softened 端)/派生(圆端，+endRingOffset 8)、horizontalPadding 10；
环 D36 线宽 4；环→文字 6；百分比 13pt medium design:.rounded monospacedDigit，预算行高 16 宽 38；
itemSpacing 30；次环 D26 线宽 2.5（内侧，同色语义）；
端部：softened（默认）= 26pt 超椭圆角（n=4、48 采样）+ flare 高 24 宽 38；round = width/2 全圆端（"一个圆定全家族曲线"）；
collapsed sliver 6×96、hit 20。

## 环（UsageRingView.swift）

- 弧从 12 点顺时针，round cap；变化动画 spring(response 0.5, damping 0.85)。
- hover halo = arcColor.opacity(0.42) shadow radius 10，**mask 挖掉中心**（只向外）；选中 scale 1.06。
- icon = centreD*0.8；无读数 icon@0.35、数字显示"—"（不是 0%）。
- 刷新：主弧 opacity 0.3（easeOut 0.2），亮段 0.16 圈 / 0.85s 用量色；busy 白弧 0.22 圈 / 1.0s 线宽 max(半宽, 1.5)。
- 时间环：外圈 hairline 2pt、gap 3、track@0.16、arc@0.7 白（本次不做）。
- 环心无深色底盘绘制（注释里的 dark disc 是历史说法）。

## 详情卡（UsageDetailCard.swift + DetailCardLayout）

宽 250、padding 18、**cornerRadius=(36+4)/2=20**（环外缘半径，一族曲线）、指针 20×40、gap 8。
contentSpacing 14、rowInternal 7、bar 高 6 **全胶囊**（Capsule）轨道 primary@0.17。
字号：标题 14 semibold / 行 11.5 / 消息 12 / 脚注 11@0.4；headerIcon 16；字体 design:.rounded（SF Rounded）。
行结构：标题独占一行 → bar → [“xx% Used” medium@0.9 | “Resets …” @0.45] 两端对齐。
形状 UsageBubbleShape：指针与身体一条路径；控制点 softened(0.24,0.44,0.55,0.24) / round(0,0.5,0.55,0.22)；尾部向体内咬 0.08×reach 防缝。
动画：行插入 opacity+offset(y:-6) easeOut 0.14 delay 0.06，移除 0.06；header 淡入 0.1 / 淡出 0.06。

## 面板动画（FloatingUsagePanelView.swift）

- 选中切换 spring(0.28, 0.84)；展开/收起 spring(0.32, 0.86)。
- 环内容淡入：展开 easeOut 0.18 delay 0.12；收起 0.10 不延迟。

## 数字

percentLabel monospacedDigit；contentTransition(.numericText()) + spring(0.5,0.85)（数字滚动，Windows 侧可简化）。

## 设置窗（Docs/ui/settings.md + settings.webp）

亮色（跟随系统）。NavigationSplitView 侧边栏（min 220 / ideal 240）+ 搜索 + 分组小标签。
行 = 左标题（黑，常规 13）+ 副标题（灰，一句话）+ 右控件；分组成白卡、hairline 分隔线。
控件：蓝 Toggle（iOS 式）、分段控件（蓝色选中块）、下拉开单。
窗 920×660（最小 720×460）；分组 Panel(外观/圆环与数字/位置与行为/Token spend) + Application(通用/通知/网络与刷新) + 账户组（订阅 vs API 分列）+ 集成/关于。

## 统计窗（spend.webp）

同亮色侧栏；Total 大数字 ~34pt bold + 灰注；蓝柱状图（圆角柱）；"By kind" 分组卡行式（标题+描述左、细灰条+数字右）；Pattern 四列小卡；By hour 蓝柱。

## Windows 侧替代决策

- SF Rounded → Segoe UI（不引第三方字体）；数字用 Typography tabular lining figures 对齐。
- 玻璃 → 纯 alpha 黑（默认降到 ~0.62）+ 可选 ACCENT_ENABLE_ACRYLICBLURBEHIND 模糊开关。
- semantic 黄档新增；阈值设置沿用现有 0.50~0.99 滑杆。
- 工具窗亮色 mac 风：白底 #FFFFFF、分组卡 #FFFFFF+hairline 边、窗底 #F5F5F7、正文黑 #1D1D1F、次要 #6E6E73、控件蓝 #0A84FF/#007AFF。
